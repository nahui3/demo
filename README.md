# Demo - Проекты демонстрации библиотек NAHUI

Этот репозиторий содержит демонстрационные проекты для библиотек NAHUI на разных платформах.

## Структура проекта

- **[android/](android/)** - Android проект с демонстрацией библиотеки [nahui3/android](https://github.com/nahui3/android)
- **[ios/](ios/)** - iOS проект с демонстрацией библиотеки [nahui3/ios](https://github.com/nahui3/ios)
- **[web/](web/)** - Web проект с демонстрацией библиотеки [nahui3/web](https://github.com/nahui3/web)

## Быстрый старт

Каждый проект содержит подробные инструкции в своем `README.md`:

- **Android**: См. [android/README.md](android/README.md)
- **iOS**: См. [ios/README.md](ios/README.md)
- **Web**: См. [web/README.md](web/README.md)

## Библиотеки

- [nahui3/android](https://github.com/nahui3/android) - Compose библиотека для Android
- [nahui3/ios](https://github.com/nahui3/ios) - SwiftUI библиотека для iOS
- [nahui3/web](https://github.com/nahui3/web) - React библиотека для Web
